WebKit. This supports a test-oracle explanation; the original checker did not
save numeric text rectangles, so their exact Firefox intersections are not
claimed here. Local Firefox launch timed out before page creation.

The authorized test repair compares fill-only `getBBox()` bounds transformed
through `getScreenCTM()`, retaining clipping, size and overlap checks and raw
client bounds for diagnosis. The [SVG interface definition](https://svgwg.org/svg2-draft/types.html#InterfaceSVGGraphicsElement)
specifies fill-only defaults. A negative control moves the first score onto
its configuration's baseline and requires rejection of that exact text pair.
Normal and visibly overlapped screenshots were inspected in both local browsers.
With fresh synthetic fixtures and no model fitting, Chromium passed **609**
checks and WebKit passed **597**, both with zero failures. WebKit used the
existing private library wrapper after its default runtime lacked ICU 74;
no dependencies were installed. A subsequently added null-transform guard was
checked directly: valid geometry passes, a null `getScreenCTM()` throws, and
restoring the transform restores identical geometry. Firefox verification of
