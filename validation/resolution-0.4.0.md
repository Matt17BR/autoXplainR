# Disposition of the 0.3.0 audit for 0.4.0

This document maps the [25 audit findings](audit-0.3.0.md) to the current repair
and its acceptance evidence. **Implemented** describes the source change;
test links identify executable acceptance checks. The
[published 0.4.0 release record](release-0.4.0.md) identifies the tagged commit,
successful CI and archive checks, and a fresh installation of the downloaded
release. Human usability testing remains unexecuted. Historical audit and
0.3.0 release records remain unchanged.

The changes alter outputs that were wrong or misleading in 0.3.0, including
binary-event probabilities, blocked permutations, ALE coordinates, diagnostic
grades and subgroup counts. Recompute affected analyses; do not treat old and
new output as numerically interchangeable. Result and aggregate evidence schemas
are now **2.0**. This is not a promise of indefinite RDS compatibility or a
migration of old serialized results.

## Calculation and evidence contracts

| Finding | Current disposition and change | Acceptance evidence | Remaining limit or required follow-up |
|---|---|---|---|
| **1. Binary event reversal** | **Implemented.** [Prediction adapters](../R/explainer.R) distinguish the native probability event from the requested event. Custom vectors can declare `probability_class`; named matrices identify their class columns. | [Event-contract tests](../tests/testthat/test-evidence-contract.R): complements, loss invariance, reversed probability effects, nonalphabetical levels, numeric/logical GLM events under reordered evaluation levels, and explicit events for GLMs without retained response levels. | A custom vector must satisfy its declared event contract; the package cannot infer the intended meaning of arbitrary numeric output. |
| **2. Invalid prediction coercion** | **Implemented.** Original types and labels are validated before normalization. Hard labels have a distinct prediction capability; probability-only losses/effects reject them. | [Prediction-type tests](../tests/testthat/test-evidence-contract.R) and [label-only accuracy tests](../tests/testthat/test-audit-statistical-repairs.R): factor regression output and unknown classes fail, valid labels retain accuracy support. | Label-only models cannot supply calibrated probability evidence. User-provided prediction functions still need correct semantics and preprocessing. |
| **3. Singleton permutation strata** | **Implemented.** [Permutation sampling](../R/permutation_importance.R) samples positions within each stratum rather than passing a singleton numeric index to `sample()`. | [Blocked-permutation tests](../tests/testthat/test-audit-statistical-repairs.R): all-singleton and mixed strata preserve membership and donor bijection; singleton-only importance is zero. | Blocking describes the specified randomization; it is not a general conditional-importance estimator. |
| **4. ALE coordinates and values** | **Implemented.** [ALE](../R/partial_dependence.R) uses occupied empirical-quantile intervals and their boundaries, includes the lower anchor, and centers linearly interpolated boundary effects over reference rows. | [ALE numerical tests](../tests/testthat/test-audit-statistical-repairs.R): exact linear recovery on irregular/tied data, nonlinear additive oracle, empirical centering and compatible boundary uncertainty. | Finite bins approximate nonlinear behavior within bins. The descriptive interval omits refitting uncertainty. Cross-package conventions must be stated before comparing values. |
| **5. Common evaluation observations** | **Implemented by rejection.** [The shared contract](../R/evidence_contract.R) requires identical ordered predictors, outcomes, class levels and positive events before paired audits. | [Ordered-data tests](../tests/testthat/test-evidence-contract.R) and [evaluation-contract tests](../tests/testthat/test-audit-statistical-repairs.R) reject reordered cases, altered outcomes and opposite event encodings. | The package does not automatically align row IDs. Users must align inputs and normalize event semantics before comparison; agreement does not establish sample independence. |
| **6. Foreign evidence attachment** | **Implemented.** [Content identities](../R/evidence_contract.R) include serializable model state, ordered evaluation contents, prediction-adapter code, declared native/positive events and current predictions. Comparison, HTML and [narrative](../R/llm_integration.R) audit/effect attachments check those identities. Identified importance overrides are also checked. | [Evidence identity tests](../tests/testthat/test-evidence-contract.R), [HTML attachment tests](../tests/testthat/test-report-brief.R), [effect provenance tests](../tests/testthat/test-audit-statistical-repairs.R) and [narrative attachment tests](../tests/testthat/test-narrative-evidence.R): reject cross-run/changed evidence, including changed adapter code with unchanged observed predictions, and accept an unchanged serialization round trip. | Identities check compatibility, not authenticity or representative sampling. Bare user-supplied importance tables have no verifiable identity and are labeled accordingly. Hidden external state of arbitrary custom functions cannot be verified beyond captured state and observed predictions; future-input equivalence is not established. |
| **7. Hidden dependence after feature selection** | **Implemented.** [Audits](../R/audit.R) assess the full predictor context separately from the displayed feature list. | [Association-context tests](../tests/testthat/test-audit-statistical-repairs.R): hiding a perfect proxy from the report leaves the unchanged feature's association result intact. | The screen remains pairwise and limited; see finding 11. |
| **8. Erased raw subgroups** | **Implemented.** [Raw evaluation context](../R/guided_workflow.R) and retained row indices are stored separately from processed model inputs. [Subgroup diagnostics](../R/subgroup_performance.R) use aligned raw groups by default. | [Data-contract tests](../tests/testthat/test-audit-data-contracts.R): missing and novel groups, context-only columns, row dropping and deliberately damaged alignment. | Small or absent groups can still lack useful performance evidence. Raw context increases the sensitive information contained in saved results and must be reviewed before sharing. |
| **9. Threshold edge metrics** | **Implemented.** [Threshold diagnostics](../R/threshold_diagnostics.R) use count-based F1 and require both class recalls for balanced accuracy. | [Independent confusion-count tests](../tests/testthat/test-audit-statistical-repairs.R): all-negative/all-positive samples, completely wrong predictions and zero denominators. | Undefined metrics remain unavailable. Threshold exploration does not authorize selecting a cutoff on final evaluation labels. |
| **10. Aggregate evidence grade** | **Implemented by removal.** [Audits](../R/audit.R) return separate shuffle, association and comparison states plus model-specific diagnostic counts. Zero-change baseline effects no longer become unsupported-claim alarms. | [Diagnostic-scope tests](../tests/testthat/test-audit-statistical-repairs.R): adding a baseline does not change primary-feature diagnostics; old grade fields are absent. [Report tests](../tests/testthat/test-report-brief.R) reject grade badges. | No diagnostic replaces evaluation adequacy, domain judgment or population inference. The schema change requires downstream consumers to stop using removed grade fields. |
| **11. Low association as reassurance** | **Implemented by restricting interpretation.** [Association findings](../R/audit.R) identify Spearman, correlation-ratio and Cramer's V screening and explicitly leave nonlinear/joint dependence unassessed. | [Nonlinear-proxy test](../tests/testthat/test-audit-statistical-repairs.R): a near-zero Spearman result still carries the unassessed-dependence qualification. | No omnibus or conditional-dependence estimator was added. Small pairwise values do not establish independence. |
| **12. H2O preprocessing before internal CV** | **Implemented by restriction.** [The H2O guard](../R/h2o_workflow.R) rejects learned external imputation, missingness-based column dropping and automatic ordinal coercion with internal CV before engine startup. | [Mocked-startup and preparation tests](../tests/testthat/test-audit-data-contracts.R): prohibited combinations fail before Java work; allowed explicit-validation and keep-missing paths remain available. | H2O's own fitted transformations remain engine responsibilities. These tests do not measure live H2O ranking effects. The separate live integration gate remains required for a release. |
